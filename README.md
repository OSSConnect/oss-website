# OSS | Let's Connect Website

Welcome to the official website repository for **OSS | Let’s Connect**!

## Community Introduction
**OSS | Let’s Connect** is a vibrant community dedicated to open-source software, mentorship, and collaboration. We aim to bridge the gap between students, professionals, and organizations by fostering a culture of open-source contributions. 

Learn more about us in our [About the Community](ABOUT_COMMUNITY.md) document.

## Website Purpose
This repository hosts the source code for our community website. The website serves as a central hub for our members to discover upcoming events, bootcamps, mentorship programs, and resources to help them start their open-source journey.

## Tech Stack
This project is built using modern web technologies:
- **Framework:** Next.js
- **UI Library:** React
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Package Manager:** pnpm
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Setup and Local Development
To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/OSSConnect/oss-website.git
   cd oss-website
   ```

2. **Install dependencies:**
   Make sure you have Node.js and [pnpm](https://pnpm.io/) installed.
   ```bash
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   pnpm dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.

## Deployment Details
This project is optimized for deployment on platforms like Vercel or Netlify. Since it is built with Next.js, deploying to [Vercel](https://vercel.com/) is recommended for a seamless, zero-configuration deployment experience.
